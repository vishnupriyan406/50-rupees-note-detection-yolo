# 50 Rupees Note Detection using YOLO11

## Project Description
An Indian currency note detection system developed using YOLO11 and Python.

## Features
- Detects Indian currency notes.
- Supports ₹10, ₹20, ₹50, ₹100, ₹200 and ₹500 notes.
- Real-time webcam detection.

## Technologies Used
- Python
- YOLO11
- OpenCV
- Ultralytics

## Model Performance
Validation mAP50: 99.5%

Note: Performance is based on a small validation dataset.

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python code/webcam.py
